## New

- **Windows: Cineo updates itself.** When a new version is out, the sidebar offers "Update to vX.Y.Z". Cineo downloads it, checks that it is signed by the Cineo release key and that every file matches its checksum, and installs it; "Restart to update" starts the new version. Nothing changes if any check fails. This works from 1.9.8 on: to get 1.9.8 itself, run the installer once more.
- **Press C to turn subtitles on or off** while a video plays on the desktop. Turning them back on brings back the same subtitle, or picks your preferred language.

## Fixed

- **Linux: the executable starts again on Ubuntu 24.04, Debian 13 and Fedora 40 or newer.** Versions 1.5.0 to 1.9.7 were built for glibc 2.43 by mistake and only ran on the newest distributions.

## Downloads

- `SHA256SUMS` is now signed with minisign (`SHA256SUMS.minisig`, key in `minisign.pub` in the repository). With `minisign` installed, `install.sh` checks the signature too.
