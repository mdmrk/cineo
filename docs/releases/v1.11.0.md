## New

- **Cloud sync, end-to-end encrypted.** Turn it on in Settings → Data to keep your library, progress, addons and most settings the same on your desktops and phones. There is no account: devices pair with a sync code, its QR code or a `cineo:///sync/` link, and everything is encrypted on the device, so the sync server cannot read it. It is off by default, and you can run your own server.
- **Android: scan the sync QR code** from Settings → Data with the camera.
- **Search in Settings**, on the desktop and on Android.
- **Desktop: playback speed** from 0.25× to 2× in the player.
- Desktop: keyboard shortcuts in Settings are shown as key caps.

## Changed

- Android: targets Android 17. When "Allow local network addresses" is on, Cineo asks for Android's local network permission and offers an "Allow" button if it is missing.
- Android: on tablets and other large screens running Android 16 or later, the player no longer shows the rotate button, because Android ignores it there.
- Updated dependencies.

## Fixed

- Desktop: the player controls and overlays fit in small windows.
- Desktop: the sidebar scrolls when it does not fit the window.
